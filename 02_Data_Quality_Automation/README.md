# Automatisation des contrôles qualité — Python

Projet de contrôle de données transactionnelles **synthétiques** : détection de doublons, valeurs manquantes et quantités invalides ; export des anomalies, taux de conformité, JSON de suivi. Utilisable comme base d'un reporting récurrent.

Exécuter d'abord `python ../01_Tableau_de_bord_Retail_KPI/retail_pipeline.py`, puis `python controle_qualite.py`.

Livrables : `outputs/registre_anomalies.csv` et `outputs/rapport_qualite.json`.
